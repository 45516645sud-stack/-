# 박람회 찾기 (Google Apps Script 버전)

순수 HTML·CSS·JS로 만든 박람회 찾기 페이지를, 파일 **딱 2개**로 Google Apps Script 웹앱에 올릴 수 있게 만든 버전입니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `Code.gs` | `doGet()` — 웹앱 진입점. `index.html`을 그대로 반환합니다. |
| `index.html` | 페이지 전체 (CSS는 `<style>`, JS는 `<script>`로 한 파일 안에 다 들어있음) |

CSS/JS를 따로 나눈 버전도 가능하지만, 붙여넣기가 훨씬 번거로워서
**한 파일에 다 넣는 방식**으로 단순화했습니다. 파일이 2개뿐이라 복사·붙여넣기가 훨씬 편합니다.

## 복사해서 넣는 방법

1. https://script.google.com/ 접속 → **새 프로젝트**
2. 기본 생성된 `Code.gs`를 지우고 이 폴더의 `Code.gs` 내용을 그대로 붙여넣기
3. 왼쪽 파일 목록에서 **+ → HTML** 눌러서 파일 이름을 `index` 로 만들고
   (확장자 `.html`은 자동으로 붙습니다) 이 폴더의 `index.html` 내용을 그대로 붙여넣기
4. 상단 **배포 → 새 배포 → 웹 앱** 선택
   - 실행 권한: **나** (executeAs)
   - 액세스 권한: **모든 사용자** (필요에 따라 조정)
5. 배포 후 나오는 URL로 접속하면 바로 동작합니다.
