# 네이버 플레이스 관리 대행 – 카톡 소개 이미지

사장님께 카톡으로 보낼 1080x1920 세로 이미지 1장을 만듭니다.

1. `config.json`의 `[ ]` 칸을 채웁니다. (서비스 이름, 가게 이름, 고칠 점 3개, 가격, 연락처)
2. `node render.js` 실행 → `place-promo.png` 생성
   - 가게마다 파일을 따로 두려면: `node render.js 가게A.json`
3. "내용이 넘칩니다" 경고가 뜨면 고칠 점 문장을 한 줄(20자 안팎)로 줄여주세요.
